Errors: soft and hard

results/deploy/errors.html

This page puts the two fault families side by side. A soft error scrambles configuration that can still be written. A hard error is aging: part of the fabric stops working and stays that way — a configuration cell that no longer takes a write, a routing select that no longer moves, a gate output shorted to a rail, a cell that takes writes only sometimes, a gate that got slower. Every number is exact %: the share of random damage draws after which the circuit computes every output bit for every input pattern, with timing added where it says so. Each table links to the page it summarises.

Soft errors: scrambled LUTs, still writable

A soft error scrambles a gate's LUT (a cosmic ray, a supply glitch) and leaves the cells writable, so anything that can write the right bits back repairs it. Each row scrambles N gates of a working circuit at once; every number is exact % on the hard substrate the fabric computes. rule: the learned update rule, forward passes only. TMR: three copies vote, nothing is repaired. scrub: rewrite from a golden copy — it repairs everything because it assumes that copy is itself safe from radiation. ECC: SEC-DED over bit-planes of the configuration. GA: genetic repair (Larchev '06), fitness from the substrate's own sweep, writing candidate configurations to the fabric. Methods and draws are those of soc.baselines compare --hard in the main repository; each circuit links to its full error page.

What the table cannot show, and the per-circuit pages do: scrubbing's golden copy has to be somewhere radiation cannot reach (put it in the same storm and it becomes the worst method), a code sized for the fault — Reed-Solomon, one symbol per gate — corrects what SEC-DED cannot, and the GA's repairs cost minutes of the fabric computing candidates where the rule takes a few steps. On soft errors the rule's claim is that it repairs without a stored answer.

Hard errors: frozen configuration cells

N cells freezes N random LUT configuration bits at random values, never writable again; N gates freezes N whole LUTs. repair: the rule grew a working circuit, then the cells died. boot: they were already dead when it started from soft wires. Methods on the same draws and starting circuits: the rule (forward passes and a re-grow watchdog, no speculative write), the fixed sweep rule, the greedy climber, the GA (cap x 100 genomes is how many configurations it writes to the fabric per repair) and, where measured, the compiler: exact synthesis told which cells are dead. rule bits is net configuration bits changed; panels measured before that column existed show rule LUT writes instead — LUT rewrites summed over every step and re-grow attempt, a much larger number and not comparable to bits. mul3 and adder4 here are 264-gate substrates; the soft-error mul3 above is a 360-gate one, and the two studies use different trained rules.

Hard errors: the rest of what aging does

A frozen cell diagnoses itself — it fails a write-and-read-back — so a compiler told which cells are dead wins wherever it has time to solve. The other aging failures are not so kind. dead selects: routing muxes that stop moving. shorted outputs: the LUT reads back perfectly and the gate emits a constant; no probe sees it. marginal cells: weak cells that lose their value and then reject a share of writes; a probe finds them only by luck. aged gates: slower gates, same function, missed clock — shown as exact and, in brackets, meets the clock. The compiler is told only what a probe reports, writes its answer to the real fabric, checks it and recompiles on bounced writes; nosee is the share of draws where it produced an exact answer to the wrong problem, timed out the share where it produced nothing. Repair regime, rewirable substrates.

The algorithm

STATE on the fabric
  theta[g, j]   LUT logits, one per gate g and cell j (sign = the config bit)
  mem[v]        the rule's recurrent memory per node (d_mem numbers)
  F[g, j]       frozen-cell mask, from the probe (write complement, read back, restore)
  rej[g, j]     which of last step's writes bounced (read-back compare)

ONE STEP  (every gate in parallel; messages only along wires)
  1  forward sweep:  evaluate the circuit hard on all 2^n_in patterns
                     -> every node's value, outputs y_hat
  2  error:          resid[p, o] = y[p, o] - y_hat[p, o]
                     err[v] = [mean resid broadcast to outputs,
                               cov(node v's activity, resid[:, o]) for each output o]
  3  backward sweep: for each pattern p and output o, walk the wires backward:
                       delta[p, o, g] = 1 if flipping gate g's output at p flips y_hat[p, o]
                       (Boolean difference: one LUT read at the neighbouring address)
                     a[p, g] = the LUT address gate g reads at pattern p
                     fix[g, j] = #{(p, o): a[p, g] = j, resid != 0, flip would correct it}
                     brk[g, j] = #{(p, o): a[p, g] = j, resid  = 0, flip would break it}
  4  encode:         h[v] = Enc([theta[v], mem[v], pos[v], err[v], rej[v], fix[v], brk[v], F[v]])
  5  one hop:        z[v] = MLP([h[v], h[pred_1(v)] .. h[pred_k(v)], sum_{succ} h[succ]])
  6  update:         d_theta[g, :]  = alpha * Head(z[g])                        # per gate
                     d_theta[g, j] += CellMLP([fix, brk, fix-brk - gate's best,   # per cell
                                                F[g, j], theta[g, j], z[g]])
                     d_theta[g, j] += beta * SWEEP_MOVE(g, j)                     # the prior:
                        SWEEP_MOVE flips (theta -> -theta) the free cell with the gate's
                        largest positive fix-brk, if any
                     d_mem[v] = alpha_m * HeadM(z[v])
  7  error gate:     gate = clip(sum |err| / tau, 0, 1)      # exactly 0 when the circuit is right
                     theta += gate * d_theta ;  mem += gate * d_mem
  8  the fabric writes theta; frozen cells reject; rej = what bounced

WATCHDOG at deployment
  attempt = 48 steps from the current configuration
  while not exact and attempts < 48:
      theta <- soft wires (odd attempts: relay slot chosen per gate to avoid its
               frozen cells; even attempts: the plain relay init), mem <- 0, F kept
      hand odd/even attempts to rule image A / rule image B
      run 48 steps
  (the gate shuts on success: no further writes until the next fault)

TRAINING  (meta-learning the weights of Enc, MLP, Head, CellMLP, alpha, beta)
  for iteration in 1..36k:
      T ~ {16, 32, 96};  n ~ Uniform(0 .. 320 cells) ramped up over the first half
      F ~ freeze n cells at random values;  arrive ~ Uniform(0 .. 48)
      theta <- soft wires;  run T steps, applying F from step `arrive` on
      loss = late-weighted BCE of the *soft* outputs across the T steps
      backprop through the whole rollout (fix/brk/F are observations, no gradient)
      Adam, lr 1e-3 (5e-4 at d_model 32), skip a non-finite update
  keep the iterate that grows a clean circuit exactly and scores best on
  boot + repair validation
