Repair does not rewind

The damaged gates are not simply restored. The policy settles on a structurally different circuit that computes the same Boolean function — degeneracy, in the paper's terms. Exported to Verilog, this repaired configuration passes all 256 input patterns in simulation and places and routes onto an iCE40 FPGA.
